Whispered Wisdom 🌸

A modern, minimalistic motivational quotes web app designed in Figma. Whispered Wisdom delivers daily quotes in a playful and soothing interface with a pastel aesthetic, featuring a friendly character, quote clouds, and interactive buttons.

💡 Project Overview

Generate random motivational quotes at the click of a button.

Beautiful cloud-style quote containers for easy readability.

Interactive button with gradient and hover effects.

Includes a custom character illustration to enhance the playful aesthetic.

Designed entirely on Figma before implementation for UI consistency.

Check out the project here: https://whispered-wisdom.vercel.app/

🛠 Tech Stack

Frontend: HTML5, CSS3, JavaScript (Vanilla)

Design & Prototyping: Figma

API: Motivational Spark API - https://motivational-spark-api.vercel.app/api/quotes/random

Tools: VS Code, Git & GitHub

⚡ Features

Random Quote Generator: Fetches motivational quotes dynamically via API.

Custom Illustrations: Friendly character and pastel aesthetic.

Hover Effects: Button changes color when hovered for a playful interaction.

Cloud Container: Quote and author neatly stacked in a visually appealing container.
